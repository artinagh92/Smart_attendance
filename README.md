# Smart Attendance 📋

A simple and practical **Smart Attendance System** built with Python.

## 📌 About the Project

**Smart Attendance** is a Python-based attendance management project designed to make recording and managing student attendance easier.

The project can be used to record attendance, manage student information, and keep track of attendance records.

## 🚀 Features

* 👨‍🎓 Student management
* ✅ Attendance recording
* 📊 Attendance tracking
* 💾 Saving attendance data
* 🐍 Built with Python
* 🖥️ Simple and easy-to-use structure

## 🛠️ Technologies

* Python
* Python Standard Library

## ▶️ How to Run

First, clone the repository:

```bash
git clone https://github.com/artinagh92/Smart_attendance.git
```

Go to the project directory:

```bash
cd Smart_attendance
```

Then run the main Python file:

```bash
python main.py
```
